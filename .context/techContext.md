# Technical Context

## Стек технологий

### Frontend
- **React**: Библиотека для построения интерфейса.
- **Vite**: Сборщик проекта для быстрой разработки.
- **Tailwind CSS**: Фреймворк для стилизации.
- **@react-pdf/renderer**: Библиотека для генерации PDF-отчетов на стороне клиента (или сервера).
- **Netlify**: Платформа для хостинга фронтенда.

### Backend
- **Node.js**: Среда выполнения JavaScript.
- **Express**: Фреймворк для создания API.
- **Cheerio**: Библиотека для быстрого парсинга HTML (статический анализ).
- **Axios**: Используется для HTTP-запросов с кастомным `httpsAgent` (ignore SSL errors, support all ciphers) для работы с российскими сайтами.
- **Deep Crawler**: Самописная логика обхода страниц (до 15 штук) с использованием очередей и конкурентных запросов для сбора SEO-статистики.
- **Google PageSpeed Insights API**: Инструмент от Google для динамического замера скорости загрузки (LCP, Score). Включает fallback-алгоритм на базе TTFB.

## Архитектура
- Проект разделен на Client и Server.
- Бэкенд развертывается отдельно (например, Heroku, Railway или VPS).
- Фронтенд на Netlify взаимодействует с API бэкенда.
